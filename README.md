# Data Visualisation with Pandas, Matplotlib and Seaborn

A notebook on visualising data with Pandas, Matplotlib and Seaborn.

## What's Inside

- Charts built from Pandas DataFrames
- Matplotlib and Seaborn plots side by side

## Tech Stack

Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

## How to Run

1. Clone the repository
2. Install the libraries: `pip install jupyter pandas matplotlib seaborn`
3. Open the notebook with `jupyter notebook` and run the cells in order
